## Code Blue: Hospital Patient Records System (CS 340, Fall 2026)
Team project with a classmate (Group 22), Oregon State University.

- **What it is:** A MySQL database for a fictional trauma center. It tracks patients, insurance plans, diagnoses, and prescriptions.
- **App:** A Python class reads all six tables and adds, changes, and deletes patient diagnoses.
- **Design:** Six normalized tables (3NF), including a many-to-many link table. Foreign keys, CHECK constraints, and input checks block bad data, such as future diagnosis dates.
- **Stored procedures:** All add, change, and delete actions, plus a full database reset, run as MySQL stored procedures.
- **Testing:** A test script runs every method, including invalid inputs that the app must reject.
- **Tech:** MySQL, SQL, Python, MySQL Workbench, draw.io, and GitHub.
- **Code:** The code is private per course policy. Access is available on request. The project builds on Oregon State CS 340 course materials, which are cited in the project.
